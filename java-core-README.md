# Student Result Manager (Java)

A console-based student result management program built with core Java.

## Features
- Add student records with a unique ID.
- Store marks for three subjects.
- Calculate each student's average and grade.
- View all records and search by student ID.
- Calculate the class average.
- Validate menu choices, IDs, and marks.

## Concepts used
Java classes and objects, constructors, arrays, `ArrayList`, loops, methods,
conditional statements, `Scanner`, and basic input validation.

## Requirements
- JDK 8 or later

## Run
```bash
javac Main.java
java Main
```

## Example workflow
Choose `1` to add students, `2` to list them, `3` to search, and `4` to
calculate the class average. Data is stored in memory and is cleared when
the program exits.

## Possible improvements
Add file storage, update/delete options, and unit tests.
